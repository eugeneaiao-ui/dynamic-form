安装与版本入口

npm install forminojs

UI 入口依赖宿主的 React、ReactDOM 和 Ant Design；兼容范围见快速开始和迁移指南。仓库名称是 Formino / formino，npm 包名是 forminojs。

npm提供已发布版本；GitHub Releases提供版本说明、匹配源码、安装包和校验文件。main 上的文档可包含尚未发版的维护改动，复现问题时应注明 npm 版本。

接入顺序

  1. 运行最小表单，确认样式、默认值与提交校验。
  2. 把业务请求封装成数据源适配器，再接入字段依赖。
  3. 为复杂联动验证清空值、零值、异步取消和条件切换。
  4. 使用实际控件和设备测量长表单；不要把示例机器的性能当成项目保证。
  5. 在服务端验证提交内容与权限。

当前边界

  • 提供表单引擎、React / AntD 适配器与示例，不包含完整拖拽编辑器或 LLM 后端。
  • JSON 配置 Schema 描述本项目支持的配置子集，不是任意 JSON Schema 的通用表单生成器。
  • 分批挂载最终会保留全部字段，不是虚拟列表。
  • 客户端校验、隐藏和禁用不能替代服务端校验与授权。

遇到问题

配置和接入问题到 Discussions；可以稳定复现的缺陷到 Issues。提供最小配置和依赖版本，避免附上真实业务数据。更多说明见 SUPPORT。
