Getting help with Formino

  • Start here: quick start, configuration and illustrated examples.
  • Usage questions: GitHub Discussions. Include your goal, configuration and dependency versions.
  • Reproducible bugs: open an issue with a minimal reproduction.
  • Feature requests: describe the user task and an example configuration in the feature request template.
  • Security reports: follow the security policy and report privately.

The npm package is forminojs; the repository and brand are Formino. Check that installation and imports use the package name, including forminojs/style.css. See adoption guidance for supported use cases and limits.

When requesting help, include the forminojs, React, ReactDOM, Ant Design and TypeScript versions, browser/Node version, expected behavior, actual behavior and the smallest relevant template/fields/adapters. Use sample values instead of business data.
