# Getting help with Formino

- **Start here:** [quick start](docs/GETTING_STARTED.md), [configuration](docs/CONFIGURATION.md) and [illustrated examples](docs/EXAMPLES.md).
- **Usage questions:** [GitHub Discussions](https://github.com/eugeneaiao-ui/formino/discussions). Include your goal, configuration and dependency versions.
- **Reproducible bugs:** [open an issue](https://github.com/eugeneaiao-ui/formino/issues/new/choose) with a minimal reproduction.
- **Feature requests:** describe the user task and an example configuration in the feature request template.
- **Security reports:** follow the [security policy](SECURITY.md) and report privately.

The npm package is **forminojs**; the repository and brand are **Formino**. Check that installation and imports use the package name, including `forminojs/style.css`. See [adoption guidance](docs/ADOPTION.md) for supported use cases and limits.

When requesting help, include the forminojs, React, ReactDOM, Ant Design and TypeScript versions, browser/Node version, expected behavior, actual behavior and the smallest relevant template/fields/adapters. Use sample values instead of business data.
